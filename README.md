# Château de sable 🏖️🏰

Jeu de sculpture de château de sable, en diorama 3D : moule des tours, trace des remparts, creuse
des tunnels et des douves, et défends ton château contre la marée montante, les vagues, les crabes
et les pirates. Treize plages du monde entier, de la Bretagne à la baie d'Ha Long.

## Jouer

👉 [Jouer en ligne](https://jpjobe.github.io/chateau-de-sable/)

À la souris (la molette zoome, deux doigts ou clic droit pour la vue) ou au doigt, téléphone en
paysage. La plage se sauvegarde dans le navigateur.

## Ce dépôt

Uniquement la version Web exportée par Godot 4.6 (moteur WebAssembly, sans threads : compatible avec
GitHub Pages). Le jeu existe aussi en application Android.
